# FilmsApp audit + Block 1 patch

## Что я проверил
- Стек: **Expo SDK 57**, **React Native**, **TypeScript**.
- Основные экраны: `Library`, `Search`, `Recommendations`, `Notes`, `Settings`.
- Данные хранятся локально в **SQLite** (`expo-sqlite`).
- По проекту уже видно, что часть ваших запросов **частично сделана**, но несколько мест недоведены до рабочего состояния.

## Уже есть в проекте
1. **Локальное хранение фильмов и заметок** через SQLite.
2. **Пользовательские API-ключи** вместо захардкоженных `.env` — это уже заложено в `provider_settings`.
3. В настройках уже есть карточки для:
   - TMDB
   - Gemini
   - OpenAI
   - Claude
   - Kinopoisk (как задел)
4. В рекомендациях уже есть поля под:
   - свободный текст вкусов
   - любимые жанры
   - нелюбимые жанры
   - любимые тайтлы
   - настроение
   - исключения
5. В БД уже есть миграция под **заголовок заметки**.
6. В БД уже есть функция `importMoviesFromNote(...)`, но **UI для неё фактически не доведён**.

## Что сейчас сломано или не доведено
1. **Заметки**
   - в БД уже требуется `title`, а экран заметок всё ещё работал как старый блокнот без отдельного заголовка;
   - из-за этого логика сохранения заметок рассинхронизирована с БД;
   - импорт списка фильмов из заметки не подключён к UI.

2. **Рекомендации AI**
   - экран рекомендаций жёстко завязан на Gemini;
   - OpenAI / Claude можно ввести в настройках, но экран их не использует;
   - поэтому ощущение "нейронка не работает" логично.

3. **Новинки за 2 недели**
   - фильтрация на TMDB есть, но лучше дополнительно отфильтровать даты на клиенте;
   - это как раз убирает старые тайтлы, которые иногда проскакивают некорректно.

4. **Смена статуса**
   - на поисковой карточке всплывают лишние `Alert`, что раздражает при частом использовании.

5. **SettingsScreen**
   - есть следы compile/runtime-проблем вокруг `expo-file-system`;
   - экспорт/импорт стоит привести к одному стабильному варианту.

## Что входит в этот Block 1 patch
### 1) Notes
- ручной заголовок заметки;
- сохранение заметок в новом формате;
- импорт фильмов из списка внутри заметки;
- разбор строк с галочками:
  - `✅`, `☑`, `[x]` → **Просмотрено**
  - `[ ]`, `☐`, обычная строка → **Запланировано**

### 2) Recommendations
- новый общий слой `src/api/recommendations.ts`;
- выбор **активного AI-провайдера** из настроек;
- поддержка:
  - Gemini
  - OpenAI
  - Claude
- свободный текст предпочтений теперь реально участвует в prompt.

### 3) Search / Latest releases
- дополнительная клиентская фильтрация новинок по датам;
- убраны лишние pop-up при смене статуса из поиска.

### 4) Settings
- исправлен экспорт/импорт через `expo-file-system` + `expo-sharing`;
- ключи скрыты в поле ввода;
- добавлены пояснения, какой провайдер реально используется.
