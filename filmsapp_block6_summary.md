# Block 6 — настройки без лишнего текста + тест API + улучшение пустых карточек

Что вошло:

1. **Темы без лишних описаний**
   - убраны длинные подписи и служебные пояснения;
   - оставлены только кнопки:
     - `Как в системе`
     - `Тёмная`
     - `Дневная`

2. **Быстрые секции в настройках**
   - сверху добавлены отдельные кнопки:
     - `API`
     - `Темы`
     - `Данные`
     - `О проекте`
   - теперь не нужно прокручивать весь экран настроек вниз.

3. **Буфер обмена для API-ключей**
   - у каждого поля появился значок буфера обмена;
   - можно вставить ключ прямо из clipboard.

4. **Кнопка `Тест` для API-ключей**
   - TMDB
   - Gemini
   - OpenAI
   - Claude
   - для Kinopoisk сейчас выводится честное сообщение, что тест пока не реализован.

5. **Улучшен вид локальных / пустых карточек в библиотеке**
   - записи без постера и данных TMDB теперь выглядят аккуратнее в `Library`;
   - при открытии такой записи больше нет ощущения, что пустой блок растянулся на весь экран;
   - вместо набора пустых секций показывается нормальная компактная локальная карточка.

## Какие файлы менять

- `package.json`
- `src/api/providerValidation.ts` — новый файл
- `src/screens/SettingsScreen.tsx`
- `src/components/MovieCard.tsx`
- `src/components/MovieDetailsModal.tsx`

## Что проверить

1. В `Настройки` больше нет лишнего текста под темами.
2. Наверху есть кнопки секций `API / Темы / Данные / О проекте`.
3. У API-ключей работает:
   - вставка из буфера;
   - кнопка `Тест`;
   - сохранение;
   - выбор активного провайдера.
4. В библиотеке локальные записи без данных TMDB выглядят компактнее.
5. При открытии такой записи модалка не забита пустыми блоками.

## Важное замечание

Для вставки из буфера я добавил зависимость `expo-clipboard` в `package.json`.
Если после замены файлов проект попросит подтянуть пакет, просто выполни установку зависимостей (`npm install` / `npx expo install`).
