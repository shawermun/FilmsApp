# PROMPTS — Готовые шаблоны для агента

## 🚀 Начало нового чата

```
Прочитай файлы в указанном порядке:
1. AGENTS.md (корень проекта)
2. ai/PROJECT_CONTEXT.md
3. ai/CURRENT_STATE.md
4. ai/ARCHITECTURE.md
5. ai/CODING_RULES.md

После прочтения опиши своё понимание проекта:
- Что это за приложение?
- Какой стек?
- Что сейчас в работе?
- Какие правила кодирования?

Если чего-то не хватает — спроси перед началом работы.
```

## ✅ После завершения задачи

```
Проверь что выполнено:
1. [ ] Запущен npx tsc --noEmit (нет ошибок TypeScript)
2. [ ] Добавлена запись в ai/CHANGELOG.md
3. [ ] Обновлён ai/CURRENT_STATE.md (если пользователь просил)
4. [ ] Обновлён ai/ARCHITECTURE.md (если менялась структура)
5. [ ] Добавлены новые баги в ai/BUGS.md (если есть)
```

## 🐛 Сообщение о баге

```
БАГ: [краткое описание]

Файл: [путь к файлу]
Строка: [номер строки]

Воспроизведение:
1. [шаг 1]
2. [шаг 2]
3. [что происходит]

Ожидалось: [что должно быть]
Фактически: [что происходит на самом деле]

Добавь это в ai/BUGS.md и исправь.
```

## ✨ Новая фича

```
ФИЧА: [название]

Что нужно сделать:
[описание задачи]

Требования:
- [требование 1]
- [требование 2]

Перед кодом:
1. Объясни план изменений
2. Покажи какие файлы будешь менять
3. После одобрения — внеси изменения
4. Запусти npx tsc --noEmit
5. Обнови ai/CHANGELOG.md
```

## 🔧 Рефакторинг

```
РЕФАКТОРИНГ: [что меняем]

Текущая проблема:
[описание проблемы]

Цель:
[что должно получиться]

Правила:
- Не ломай существующее API
- Минимальные изменения
- Обязательно npx tsc --noEmit после
```
