# PROJECT CONTEXT

## Что за проект

**FilmsApp** — локальное мобильное приложение для учёта фильмов и сериалов. Без регистрации, без облачной синхронизации, все данные хранятся на устройстве.

## Цель

Пользователь может:
- Вести библиотеку просмотренного и запланированного
- Ставить оценки и писать отзывы
- Искать фильмы через TMDB
- Получать ИИ-рекомендации на основе вкусов
- Вести заметки о фильмах

## Технологический стек

| Технология | Версия | Назначение |
|-----------|--------|-----------|
| **Expo** | SDK 57 | Платформа разработки |
| **React Native** | 0.86 | UI фреймворк |
| **React** | 19.2 | Библиотека |
| **TypeScript** | 6.0 | Язык (strict mode) |
| **SQLite** | expo-sqlite | Локальная база данных |
| **React Navigation** | 7 | Навигация (bottom tabs) |

## API и сервисы

| Сервис | Роль | Примечание |
|--------|------|-----------|
| **TMDB** | Единственный источник данных о фильмах | Поиск, детали, постеры |
| **Gemini** | Основной AI provider | Рекомендации |
| **OpenAI** | Альтернативный AI provider | Рекомендации |
| **Claude** | Альтернативный AI provider | Рекомендации |
| **Кинопоиск** | Задел на будущее | Не используется сейчас |

## Ключевые особенности

1. **Локальность** — нет аккаунтов, нет синхронизации, всё в SQLite
2. **Переключаемые AI providers** — пользователь выбирает Gemini/OpenAI/Claude
3. **Тёмная/светлая тема** — управляется через ThemeContext
4. **Офлайн-first** — приложение работает без интернета (кроме TMDB/AI)
