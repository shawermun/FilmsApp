# AGENTS — Дополнительные правила

> Основной документ: `AGENTS.md` в корне проекта. Этот файл содержит дополнительные инструкции.

## Обязательный порядок чтения

Перед началом любой задачи прочитай:
1. `PROJECT_CONTEXT.md` — контекст проекта
2. `CURRENT_STATE.md` — текущий фокус разработки
3. `ARCHITECTURE.md` — структура и потоки данных
4. `CODING_RULES.md` — правила кодирования
5. `BUGS.md` — известные баги

## Жёсткие запреты

- **НЕ** придумывай отсутствующие API — используй только существующие
- **НЕ** рефактори код без явного запроса
- **НЕ** переписывай большие файлы (>100 строк) без необходимости
- **НЕ** используй `any` в TypeScript без крайней необходимости
- **НЕ** ломай существующую архитектуру

## Обязательные действия

| Когда | Что делать |
|-------|-----------|
| Перед кодом | Объясни план изменений |
| После изменений | Запусти `npx tsc --noEmit` |
| После задачи | Добавь запись в `CHANGELOG.md` |
| Новый баг | Добавь в `BUGS.md` с воспроизведением |
| Новое правило | Добавь в `CODING_RULES.md` |
| Изменилась архитектура | Обнови `ARCHITECTURE.md` |

## CURRENT_STATE.md

Обновляй **только по явному указанию пользователя**. Не меняй автоматически после каждой сессии.
