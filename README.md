## 📖 О приложении

**FilmsApp** — мобильное приложение для тех, кто устал забывать, что уже посмотрел и что собирался посмотреть.

Вы ведёте свою библиотеку фильмов, ставите оценки, пишете рецензии и заметки — а встроенный ИИ анализирует именно **вашу** коллекцию и подсказывает, что посмотреть дальше. Без аккаунтов, без облака, без слежки: вся библиотека живёт в локальной базе SQLite на вашем телефоне.

## ✨ Возможности

### 🤖 ИИ-рекомендации на основе вашей библиотеки

Рекомендации строятся не на абстрактных «популярных фильмах», а на том, что вы реально смотрели и как оценили. Модель получает вашу библиотеку, оценки и предпочтения — и предлагает фильмы, которые действительно подходят под ваш вкус.

### 🧠 Выбор нейросети — за вами

Поддерживаются три провайдера, переключение прямо в настройках:

| Провайдер | Статус |
|-----------|--------|
| Google **Gemini** | ✅ поддерживается |
| **OpenAI** (GPT) | ✅ поддерживается |
| Anthropic **Claude** | ✅ поддерживается |

Не нравится результат одной модели — переключились на другую в два тапа. Архитектура построена на адаптерах, поэтому логика приложения не привязана к конкретному вендору.

### 🔑 Свои API-ключи

Приложение работает на **ваших** ключах, которые вы вводите в настройках:

- ключ выбранного ИИ-провайдера;
- ключ TMDB для поиска фильмов и загрузки постеров.

Ключи хранятся локально на устройстве и используются только для прямых запросов к выбранному вами сервису. В коде проекта нет и не должно быть никаких зашитых секретов.

### 📝 Добавление фильмов текстом и через заметки

Не нужно искать каждый фильм вручную по одному. Напишите список или просто текст в свободной форме — например, после разговора с друзьями или списка из поста, — и приложение распознает названия фильмов, найдёт их в TMDB и добавит в библиотеку.

```
«Посмотреть: Дюна, Прибытие, что-то от Вильнёва ещё,
и тот фильм про пианиста в Варшаве»
```

→ распознаётся → сверяется с TMDB → попадает в библиотеку.

### 🔍 Поиск и карточки фильмов

- Поиск по базе TMDB с постерами, годом, рейтингом и описанием.
- Подробная карточка фильма: обзор, жанры, актёрский состав и съёмочная группа.
- Фильмография актёров и режиссёров — переход в один тап.
- Корректная обработка неполных данных: без постера, без даты, без описания приложение не ломается.

### 📚 Библиотека со статусами и фильтрами

- Статусы фильмов: запланировано, просмотрено и другие состояния.
- Фильтры и сортировка, чтобы быстро находить нужное в большой коллекции.
- Личные оценки по каждому фильму.

### ⭐ Рецензии и заметки

- Собственные рецензии с оценкой — отдельный раздел, где собраны все ваши отзывы.
- Свободные заметки: мысли, списки к просмотру, цитаты.

### 🎨 Темы оформления

Светлая и тёмная тема с сохранением выбора между запусками.

## 🔒 Приватность

Это ключевой принцип проекта, а не маркетинговая строчка:

- 🗄️ **Библиотека, оценки, рецензии и заметки хранятся только на устройстве** в локальной базе SQLite.
- ☁️ **Нет своего сервера.** Приложению просто некуда отправлять ваши данные — бэкенда не существует.
- 👤 **Нет регистрации и аккаунтов.** Ни почты, ни телефона, ни профиля.
- 📊 **Нет аналитики и трекеров** пользовательского поведения.
- 🔐 **API-ключи остаются на устройстве** и уходят только напрямую в тот сервис, которому предназначены.

Единственные внешние запросы — те, что вы инициируете сами: поиск фильма в **TMDB** и запрос рекомендаций у **выбранного вами ИИ-провайдера**. Удалили приложение — данные исчезли вместе с ним.

## 🚀 Запуск проекта

### Требования

- Node.js 20+
- npm
- Expo Go на телефоне либо Android/iOS-эмулятор

### Установка

```bash
git clone https://github.com/shawermun/FilmsApp.git
cd FilmsApp
npm install
npm start
```

Дальше отсканируйте QR-код приложением Expo Go или запустите на эмуляторе клавишей `a` (Android) / `i` (iOS).

### Настройка ключей

API-ключи вводятся **в самом приложении**, в разделе «Настройки»:

1. Получите ключ TMDB — бесплатно на [themoviedb.org](https://www.themoviedb.org/settings/api).
2. Получите ключ у выбранного ИИ-провайдера:
   - [Google AI Studio](https://aistudio.google.com/app/apikey) — Gemini
   - [OpenAI Platform](https://platform.openai.com/api-keys) — GPT
   - [Anthropic Console](https://console.anthropic.com/settings/keys) — Claude
3. Вставьте ключи в настройках и выберите провайдера для рекомендаций.

> ⚠️ Никогда не коммитьте свои ключи в репозиторий. Файл `.env` добавлен в `.gitignore`.
