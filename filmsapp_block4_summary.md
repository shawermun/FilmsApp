# Block 4 — тема приложения (безопасная интеграция)

Я специально сделал **безопасный вариант**, чтобы не затереть уже подготовленные блоки 1–3.

## Что входит

1. **ThemeContext + ThemeProvider**
   - тема теперь централизована;
   - есть режимы `system`, `dark`, `light`;
   - выбор темы хранится локально.

2. **Локальное сохранение темы**
   - новый файл `src/database/appSettings.ts`;
   - создаётся таблица `app_settings`;
   - туда сохраняется `theme_mode`.

3. **Новые палитры**
   - `src/constants/theme.ts` теперь содержит:
     - `DARK_COLORS`
     - `LIGHT_COLORS`
     - helpers для навигационной темы
     - типы `ThemeMode`, `ThemeColors`

4. **App.tsx обновлён**
   - навигация и `StatusBar` реально переключаются по теме;
   - тема применяется на уровне корня приложения.

5. **SettingsScreen обновлён**
   - добавлен блок выбора темы;
   - пользователь может выбрать:
     - как в системе
     - тёмная
     - светлая
   - выбор сохраняется локально.

## Какие файлы менять

- `App.tsx` — заменить целиком
- `src/constants/theme.ts` — заменить целиком
- `src/screens/SettingsScreen.tsx` — заменить целиком
- `src/context/ThemeContext.tsx` — создать новый файл
- `src/database/appSettings.ts` — создать новый файл

## Почему сделал именно так

Есть 2 пути:

### Вариант A — безопасный
Добавить **инфраструктуру темы** и экран выбора темы, не переписывая весь UI проекта сразу.

**Плюсы:**
- не откатывает предыдущие блоки;
- мало риска сломать карточки, модалки и логику;
- можно ставить прямо сейчас.

**Минусы:**
- это ещё не полная тотальная theme-migration всех экранов/карточек.

### Вариант B — агрессивный
Сразу переписать все экраны, карточки и модалки под dynamic theme hook.

**Плюсы:**
- полностью переключаемый UI везде.

**Минусы:**
- высокий риск случайно затереть уже подготовленные изменения из Block 1 / 2 / 3;
- объём патча сильно больше.

## Рекомендация

Я рекомендую **сначала поставить этот безопасный Block 4**, а потом отдельным следующим блоком сделать **полную theme-migration UI-компонентов**.

Так ты не потеряешь уже собранные фичи по:
- заметкам
- AI-рекомендациям
- карточке фильма
- фильтрам поиска

## Что проверить после вставки

1. В `Настройки` появился блок выбора темы.
2. Выбор `Тёмная / Светлая / Как в системе` сохраняется после перезапуска приложения.
3. `StatusBar`, header и bottom tabs меняют оформление вместе с темой.
4. Настройки визуально переключаются сразу.
