# FilmsApp Block 2 — movie details UX

## Что делает этот блок
Этот пакет закрывает большой кусок запросов вокруг карточки фильма:

1. **Кнопка смены статуса перенесена вниз экрана**
   - больше не висит в правом верхнем углу;
   - живёт поверх экрана снизу;
   - при скролле вниз прячется, при скролле вверх плавно возвращается.

2. **Жанр и длительность вынесены отдельно**
   - больше не спрятаны в «интересных фактах»;
   - показываются отдельными карточками сверху.

3. **Личные отзывы и оценки теперь можно редактировать прямо в карточке**
   - оценка 1–10;
   - текстовый отзыв;
   - сохранение в локальную БД;
   - эти данные дальше может использовать экран рекомендаций.

4. **Режиссёр и сценаристы вынесены отдельно**
   - режиссёр и сценаристы отображаются сразу;
   - остальная команда прячется под кнопкой **«Ещё команда»**.

5. **Актёры теперь с фото**
   - по нажатию открывается отдельный экран с фильмографией актёра/члена команды;
   - это частично закрывает запрос «посмотреть, в каких фильмах/сериалах снимался выбранный актёр».

6. **TMDB API расширен**
   - добавлены методы для загрузки данных о человеке и его combined credits.
