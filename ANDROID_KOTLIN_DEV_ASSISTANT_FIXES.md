Кратко, что изменено

1. Библиотека
- фильтры переведены с horizontal FlatList на ScrollView;
- чипы получили фиксированную высоту, центрирование текста и запрет на растягивание;
- длинные подписи вроде «Запланировано» больше не должны обрезать нижние элементы букв на Android.

2. Поиск
- стартовая выдача теперь показывает новинки за текущий год, а не только за 2 недели;
- панель фильтров переработана: крупные читаемые чипы, wrap-layout, более понятные подписи;
- экран переведён на ThemeContext-цвета вместо статической палитры.

3. AI-рекомендации
- Gemini переведён с SDK на прямой REST-вызов, чтобы убрать проблемы совместимости Expo / React Native;
- тест API-ключа Gemini в настройках тоже переведён на REST;
- добавлен режим «Угадать фильм по описанию».

4. Техническое замечание по архиву
- исходное вложение было RAR-архивом с расширением .zip;
- при извлечении 3 файла оказались повреждены;
- app.json восстановлен в рабочем Expo-виде;
- src/api/gemini.ts заменён на compatibility-заглушку, потому что логика вынесена в recommendations.ts/providerValidation.ts.
